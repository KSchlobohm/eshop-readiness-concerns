# Order total sample

A small console application that calculates an order total from a unit price,
quantity, and discount percentage.

Requires the .NET 10 SDK.

Run the application:

```powershell
dotnet run --project .\OrderApp\OrderApp.csproj
```

Run the calculation tests:

```powershell
dotnet test .\OrderApp.Tests\OrderApp.Tests.csproj
```
